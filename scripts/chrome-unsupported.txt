# Fixtures whose feature Chrome does not implement.

# The visual harness gates on "did this fixture get further from Chrome", which
# only works when Chrome's render is the thing we want. For a feature Blink has
# never implemented, the reference encodes "the feature does nothing" — so if
# our implementation broke and fell back to Chrome's behaviour, the diff would
# go *down* and a one-sided gate would call that an improvement.
#
# These are still rendered, diffed and reported, but excluded from the mean and
# from the regression gate. Correctness for them lives in the parity
# expectations and the unit tests instead.
#
